About

I am a CSCI major at Hunter College who likes building tools that automate repetitive work.

Most of my projects start as a small script to save a few minutes a day and grow into full systems with databases, web interfaces, and background services.

Projects

  • File Pipeline Automation

    Python and PowerShell scripts that read embedded file metadata, then automatically tag, sort, and organize files into collections. Background watchers process new files as they arrive.

  • SQLite Search Database and Web Gallery

    A SQLite database with full-text search over thousands of records, served by a Python web server with a JSON API and a browser front end for searching and filtering.

  • Discord and Telegram Bots

    Python bots that take chat commands, queue jobs, call a REST API, and post results back. They run as scheduled tasks that restart automatically.

  • Script Dashboard

    An AutoHotkey v2 desktop dashboard with a live search filter for launching and managing my Python and PowerShell scripts from one window.
